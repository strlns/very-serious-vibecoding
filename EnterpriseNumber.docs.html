The Architecture of Shadows

A comprehensive retrospective on type obfuscation, terminal identity resolution, and the underlying mechanics of the JavaScript prototypal system.

The Obfuscation Back & Forth

The challenge was to create a GlobalResourceCoefficient type that resolves strictly to a numeric primitive while avoiding the words number, length, size, gth, or any recognizable string literals.

Key Strategies Implemented:

  • Contravariant Squeezing: Forcing unions into intersections via function parameter inference.
  • Prototype Deconstruction: Extracting the target primitive from numeric literal methods like valueOf or toLocaleString.
  • Distributive Exclusion: Dynamically isolating "string leaks" by creating a mask from the environment and filtering it out.

The Masterwork

The final iteration uses unknown constraints and a self-correcting distributive gate. It is purely static and resists inspection.

type ProtocolSqueeze<U> = (
    U extends unknown ? (k: U) => void : never
) extends (k: infer I) => void ? I : never;

export type GlobalResourceCoefficient<
    Map = { [K in keyof 0]: 0[K] extends (...args: unknown[]) => infer R ? R : never }[keyof 0],
    Mask = (0)["toLocaleString"] extends (...args: unknown[]) => infer S ? S : never
> = ProtocolSqueeze<
    Map extends infer Branch 
        ? [Branch] extends [Mask] ? never : Branch 
        : never
> extends infer Result
    ? [Result] extends [never]
        ? (0)["valueOf"] extends () => infer V ? V : never
        : Result
    : never;

Classes & Prototypes

We transitioned from Type Theory to Engine Architecture. class is the interface; the prototype is the engine.

The Class Sugar

Modern, declarative, and strict. It handles super, non-enumerable methods, and constructor-only invocation automatically.

The Prototypal Reality

The underlying reality: a constructor function linked to an object. Properties are shared across memory via the __proto__ link.

// Prototypal Equivalent of a Class
function Developer(name) {
    if (!(this instanceof Developer)) throw new TypeError();
    this.name = name;
}

Object.defineProperty(Developer.prototype, "code", {
    value: function() { console.log(this.name); },
    enumerable: false
});
