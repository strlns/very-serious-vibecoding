Superscope editor (like the original AVS effect)
Variable cheat sheet
i point index 0–1 · v level at point · b 1 on a beat, otherwise 0 · x, y output position (-1…1) · n point count · sin cos tan abs sqrt pow sign rand(n) if(c,a,b) · custom variables may be named freely and persist between frames.
Expert mode: raw preset JSON

Technology: Rendering uses webvs (WebGL), loaded from unpkg. Presets are Superscope definitions in the webvs JSON format, modeled after the classic AVS Superscope language.

More resources: azeem/webvs · npm package · official test page · awesome-avs (more presets and converters for .avs files).
